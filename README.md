# Seedlands

The website of Seedlands, the 3D seed map for Minecraft on iPhone and iPad: its support and
privacy pages, and the Seedlands Link mod that lets the map follow you live in Java Edition.

- Site: https://mfrports.github.io/seedlands-app/
- Help, or a map that doesn't match your world: open an issue here.

Seedlands is an independent app. NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR
ASSOCIATED WITH MOJANG OR MICROSOFT.
